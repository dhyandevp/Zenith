## Output Requirements

When improving the website, generate:

1. Updated landing page
2. Hero section
3. Navigation
4. Bento Grid showcase
5. Feature section
6. Search interaction
7. Collections preview
8. Testimonials
9. Pricing
10. Footer

Also improve:

- spacing
- typography
- hierarchy
- accessibility
- responsiveness
- interaction design
- animations
- usability

Prefer visual improvements over additional text.

If a section feels generic, redesign it instead of refining it.

Always explain why the redesign better supports Zenith's vision.
