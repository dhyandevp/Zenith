Aurora Forest Design Language

Version: 2.0

Status: Official

1. Philosophy

Zenith is not a dashboard.

Zenith is not productivity software.

Zenith is not another bookmark manager.

Zenith is a Digital Museum.

Every interaction should feel like placing a beautiful object into a carefully curated collection.

The interface should disappear.

The user's content should become the artwork.

2. Design Principles
Content is the Hero

The interface exists only to support content.

Movie posters.

Book covers.

Album art.

Game artwork.

GitHub repositories.

Everything saved becomes part of the visual experience.

Quiet Luxury

No flashy gradients.

No neon.

No unnecessary animations.

No decorative effects.

Beauty comes from restraint.

Organic Technology

Technology should feel warm.

Not cold.

Not corporate.

Soft lighting.

Natural spacing.

Rounded geometry.

Editorial composition.

Timelessness

The interface should look beautiful in five years.

Never chase design trends.

20. Design Review Checklist

Before any screen is accepted:

Uses only Aurora Forest colors.
Never uses pure black.
Never uses colors outside the palette.
Uses Space Grotesk + Inter + JetBrains Mono only.
Follows the spacing scale.
Follows the motion system.
Uses the Bento Grid for saved content.
Search remains the primary interaction.
Feels handcrafted rather than template-based.
Could be recognized as Zenith even without the logo.
